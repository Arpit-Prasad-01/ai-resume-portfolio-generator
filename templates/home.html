How PortfolioAI Works

A simple student project brief designed to automate your web presence.

1. Resume Input

Place your resume content inside a plain text or PDF file (resume.txt). The app reads, validates, and cleans unnecessary spaces automatically.

2. Gemini API Processing

Your resume text is sent securely to the Gemini model using a controlled prompt to extract structured JSON (Skills, Experience, Projects, Education).

3. Portfolio HTML Generation

Python converts the structured JSON data into dynamic HTML/CSS templates, saving a fully functional portfolio.html ready to view or download.
